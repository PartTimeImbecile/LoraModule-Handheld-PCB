# LoraModule-Project-PCB
A simple pcb I created for combining an ESP32S3 Supermini and a wide variety of Lora SMD chips such as the RA-01SH

Many other RA-xxx chips share the same footprint but ensure to check this for yourself

Along with this, the supermini s3 shares a footprint with many other superminis, but once again this is at user discretion and some code modification may be needed, but as far as i know they should be similar enough to work almost without any issues.
